## What's new

- One-line installers for OpenClaw hosts: `install-plugin.sh` (Linux, macOS, WSL) and `install-plugin.ps1` (Windows, beta). They verify a signed feed, snapshot the store, install through `openclaw plugins`, and roll back on a failed check. Also `--rollback`, `--uninstall`.
- `openclaw plur1bus selftest` checks the plugin in a throw-away store.
- Hermes host mode: `--host hermes` (`-Host hermes` in the `.ps1`) installs the memory provider into a Hermes agent (0.21.4 or newer) with a local sidecar (binary pinned by SHA-256 in the feed). No Node: pinned portable Node 24.21.0.
- Build attestations and npm provenance; snapshots outside the state directory (`snapshotsDir`).
- Voice rooms: Persona or Light, switched with `/modus`.
- Dashboard: health watch (LLM failures, gateway signals).

## Fixes

- Store snapshots retry when a table is compacted during the copy.
- A fresh state directory without `openclaw.json` is no longer an invalid config.
- Skill-Miner clustering no longer blocks the gateway.
- Long messages no longer trigger duplicate critical pushes.

## Upgrade notes

- No store migration; existing installs keep configuration and embedding choice.
- Optional `runtime.detachPostTurnWork` (off by default): post-turn work runs outside the turn.
- An install from `install-memory-system.sh` needs `--adopt-legacy`; disable the `protect-plur1bus-deploy.sh` cron line first.
- Details: `docs/distribution.md`.
