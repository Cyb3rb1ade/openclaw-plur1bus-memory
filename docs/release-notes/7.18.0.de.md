## Neu

- Hermes-Hostmodus: `install-plugin.sh --host hermes` und `install-plugin.ps1 -Host hermes` installieren den PLUR1BUS-Memory-Provider in einen Hermes-Agenten (ab 0.21.4), mit einem lokalen PLUR1BUS-Sidecar, der den Speicher hält. Die Sidecar-Binary ist im signierten Feed festgelegt und per SHA-256 geprüft.
- Ein Agent pro Hermes-Home oder -Profil (`--hermes-profile`). Ein anderer Memory-Provider wird nur mit `--replace-provider` ersetzt und bei Rollback und Deinstallation wiederhergestellt.
- Update mit Speicher-Snapshot und Binary-Rollback, Deinstallation und ein Purge, der verweigert, solange ein anderes Hermes-Home den Sidecar nutzt.
- Ein Hermes-Rechner ohne Node bekommt für den Installer ein festgelegtes, hash-geprüftes portables Node 24.21.0.

## Korrekturen

- Speicher-Snapshots können außerhalb des OpenClaw-Statusverzeichnisses liegen (`snapshotsDir`).

## Hinweise zum Upgrade

- OpenClaw-Installationen bleiben unverändert; keine Speichermigration.
- Gespeicherte Installer-Bundles von 7.17.x lehnen den neuen Feed ab (er enthält `hosts.hermes`); die Einzeiler laden immer das aktuelle Bundle.
- Details: `docs/distribution.md`, Abschnitt „Hermes host mode“.
