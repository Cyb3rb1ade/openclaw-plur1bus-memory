## What's new

- Hermes host mode: `install-plugin.sh --host hermes` and `install-plugin.ps1 -Host hermes` install the PLUR1BUS memory provider into a Hermes agent (0.21.4 or newer), with a local PLUR1BUS sidecar that holds the store. The sidecar binary is pinned by the signed feed and checked by SHA-256.
- One agent per Hermes home or profile (`--hermes-profile`). Another memory provider is replaced only with `--replace-provider` and restored on rollback and uninstall.
- Update with a store snapshot and binary rollback, uninstall, and a purge that refuses while another Hermes home uses the sidecar.
- A Node-less Hermes machine gets a pinned, hash-checked portable Node 24.21.0 for the installer.

## Fixes

- Store snapshots can live outside the OpenClaw state directory (`snapshotsDir`).

## Upgrade notes

- OpenClaw installs are unchanged; no store migration.
- Saved 7.17.x installer bundles reject the new feed (it carries `hosts.hermes`); the one-liners always fetch the current bundle.
- Details: `docs/distribution.md`, section "Hermes host mode".
