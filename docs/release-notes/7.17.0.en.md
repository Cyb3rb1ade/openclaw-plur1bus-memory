## What's new

- One-line installers for OpenClaw hosts: `install-plugin.sh` (Linux, macOS, WSL) and `install-plugin.ps1` (Windows, beta). They verify a minisign-signed feed, snapshot the memory store, install or update the plugin through `openclaw plugins`, and roll back on a failed check.
- `openclaw plur1bus selftest` checks the plugin end to end in a throw-away store, without touching your memories or credentials.
- Adoption of an rsync deploy (`--adopt-legacy`), `--rollback`, `--uninstall` with an optional purge.
- Release artefacts carry build attestations; the npm package, when published, carries provenance.

## Fixes

- Store snapshots retry when a table is compacted during the copy and refuse a store inside the harness home.
- A fresh state directory without `openclaw.json` no longer counts as an invalid config.

## Upgrade notes

- No store migration. Existing installs keep their configuration and embedding choice.
- An install from `install-memory-system.sh` needs `--adopt-legacy`; disable the `protect-plur1bus-deploy.sh` cron line first.
- Details: `docs/distribution.md`.
