## Deviations from the original plan

1. **Config schema simplified.** Removed `minScore` and `mode` from `contradictionDetection` because no code consumed them. Added `config-audit.test.js` assertions for the remaining fields.
2. **Ranking uses strict lexicographic ordering.** The original plan proposed a weighted scoring function. The implementation instead uses strict comparison: `versionNumber` → `status === "active"` → authoritative `updateSource` → recency → first argument.
3. **Formatter hardened beyond the plan.** Added handling for empty/missing `supersededBy`, non-finite `versionNumber`, quote injection, and malformed `status`.
4. **Symmetric persistence.** Each detected contradiction is persisted twice (once per memory id) so either side can later retrieve it.
5. **Integration test realized via formatter output.** Because mocking the full auto-recall LanceDB path is impractical, the end-to-end test simulates the resolution step and asserts the rendered context.

## Which K1/H1 findings are addressed

- **K1-06 Memory-Text Contradiction Safety**: active fact-memories are checked for contradiction before prompt injection.
- Corrected memories win over older conflicting facts via `versionNumber`, `updateSource`, and recency.
- Old records remain in the database; only the in-context copy is marked as superseded.
