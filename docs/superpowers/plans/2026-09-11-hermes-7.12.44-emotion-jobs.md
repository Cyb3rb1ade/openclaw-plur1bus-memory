# Hermes 7.12.44 Deferred Emotion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove default auto-tier T3 emotion inference from capture and refine eligible memories through a scoped bounded background job.

**Architecture:** Separate local classification confidence from emotional intensity. Persist pending/final state in native card metadata consumed by recall, and use exact source revalidation before background updates. Preserve explicit inline/fixed-tier operator choices.

**Tech Stack:** Python, LanceDB metadata, native job gates, deterministic backend fixtures.

**Spec:** `docs/superpowers/specs/2026-09-11-hermes-7.12.44-design.md`
