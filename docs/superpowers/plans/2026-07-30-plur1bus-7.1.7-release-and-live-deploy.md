# PLUR1BUS 7.1.7 Release and Live Deployment Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the verified model-free feature-cron fix as immutable PLUR1BUS 7.1.7 artifacts on GitHub and ClawHub, then deploy that exact release to the live OpenClaw system with a snapshot and rollback point.

**Architecture:** Release metadata is prepared on an isolated branch rooted at commit `0a76fe7314a171d81865aca685f59b6791f8f155`. One canonical npm tarball is built and hashed, the source commit is tagged only after GitHub integration, and ClawHub is source-linked to the same immutable tag. Live deployment snapshots memory/config first, pins `/root/.openclaw/plur1bus-release` to the tag, installs the canonical tarball, applies only the shipped cron direct-dispatch host patch, reconciles owned feature crons, and verifies gateway and cron state.

**Tech Stack:** Git, Node.js/npm, GitHub CLI, ClawHub CLI, OpenClaw CLI, systemd user services

## Global Constraints

- Release version is exactly `7.1.7`; existing versions `7.1.4` through `7.1.6` remain immutable.
- Source commit must contain `0a76fe7314a171d81865aca685f59b6791f8f155`.
- Production data and configuration are snapshotted before mutation.
- The six afterthought/classifier feature jobs keep their 30-minute schedules.
- No outer carrier model may run for the exact PLUR1BUS internal feature commands.
- No `thinking: off` override is introduced; Kimi keeps host-native model/thinking policy.
- Existing unrelated user changes in `/root/openclaw-plur1bus-memory` are never included or modified.
