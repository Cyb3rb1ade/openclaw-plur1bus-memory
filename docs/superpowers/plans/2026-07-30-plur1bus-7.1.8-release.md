# PLUR1BUS 7.1.8 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the merged feature-cron configuration-timeout fix as immutable PLUR1BUS 7.1.8 artifacts on GitHub and ClawHub.

**Architecture:** Prepare synchronized release metadata on an isolated branch rooted at merged `origin/main` commit `53790ee1158d6e747009e4fb8bdfecab70944ffe`. Build and verify one canonical npm tarball, integrate the release metadata through a green pull request, tag the exact merged tree, then publish and independently verify GitHub and ClawHub artifacts.

**Tech Stack:** Git, Node.js/npm, GitHub CLI, GitHub Actions, ClawHub CLI.

## Global Constraints

- Release version is exactly `7.1.8`; tag and package versions through `7.1.7` remain immutable.
- The source must contain PR #91 and commit `842bd54d624df14d795c0d43378d9c0eb8362971`.
- Only the redacted feature-cron `config.get` timeout changes from 15,000 to 30,000 ms.
- No retry, shared CLI timeout, cron schedule, delivery, model route, or thinking policy changes are included.
- Existing unrelated changes in `/root/openclaw-plur1bus-memory` remain untouched.
- This release does not deploy or mutate the live OpenClaw installation.
