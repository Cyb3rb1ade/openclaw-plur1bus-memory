# Hermes 7.12.44 Storage and Lifecycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make native capture retries preserve journal identity, prevent heuristic temporal narrowing from emptying valid recall, and safely retire provably stale knowledge proposals.

**Architecture:** Extend the existing scoped Python runtime, not the OpenClaw hook API. Persist capture identity at admission, carry it through durable retries, and make derived journal writes idempotent. Reuse existing exact writer locks and authorization predicates.

**Tech Stack:** Python, LanceDB, JSONL, pytest/unittest, native scoped runtime.

**Spec:** `docs/superpowers/specs/2026-09-11-hermes-7.12.44-design.md`
