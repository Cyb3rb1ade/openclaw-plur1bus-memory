# PLUR1BUS Hermes 0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Integrate PLUR1BUS `v7.2.6` into the dedicated Hermes branch and publish the independently versioned `hermes-v0.3.0` installer release without changing the OpenClaw main release.

**Architecture:** Preserve the existing merge-based Hermes branch history: merge the immutable upstream tag, retain the Python provider/controls adapter and installer surfaces, then synchronize release metadata. Build and validate one npm/OpenClaw artifact that remains OpenClaw-compatible while carrying the Hermes installer, and publish it through the same prerelease and GitHub Packages channels as `hermes-v0.2.0`.

**Tech Stack:** Git, Node.js 22+, npm/GitHub Packages, Python 3.11+, pytest, setuptools, Bash, Hermes plugin manifests, GitHub CLI.

## Global Constraints

- OpenClaw/npm package version is exactly `7.2.6-hermes.1`.
- Hermes Python provider, controls package, and both plugin manifests are exactly `0.3.0`.
- Git tag is exactly `hermes-v0.3.0`.
- GitHub release title is exactly `PLUR1BUS Hermes 0.3.0 — 7.2.6 installer release`.
- `main`, tag `v7.2.6`, and the existing 7.2.6 GitHub release remain unchanged.
- The release is a GitHub prerelease and mirrors the installation, artifact, and package-channel structure of `hermes-v0.2.0`.
- GitHub Packages receives `@cyb3rb1ade/plur1bus-memory@7.2.6-hermes.1` with dist-tag `hermes`; dist-tag `latest` remains unchanged.
- Existing Hermes homes, profiles, LanceDB stores, credentials, model routes, and local services are outside the build write scope.
- No force push, history rewrite, tag movement, or replacement of an existing release is allowed.
- The installer must preserve automatic Hermes-home discovery, multi-instance selection, explicit noninteractive home selection, provider-independent Jina setup, populated-store protection, and OpenClaw compatibility.
