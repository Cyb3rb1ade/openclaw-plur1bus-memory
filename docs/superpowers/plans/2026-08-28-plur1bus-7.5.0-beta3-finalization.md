# PLUR1BUS 7.5.0 / OpenClaw Beta 3 Finalization Plan

> **Execution note:** Follow this plan serially. Do not delegate repository work because the release candidate, evidence chain, and shared Docker state must remain under one owner. Apply systematic debugging and test-driven development to every defect; run verification-before-completion before any PASS claim.

**Goal:** Produce and verify one immutable, fully committed PLUR1BUS 7.5.0 npm artifact against exactly OpenClaw 2026.8.1-beta.3 without modifying the live host system.

**Architecture:** Preserve the current development worktree as evidence, commit only reviewed 7.5.0 changes, then create a clean final worktree at that commit. Build a multi-stage Docker image from the clean commit, install the resulting tarball through OpenClaw's real `npm-pack:` installer, and run all runtime tests in fresh prefixed resources. Re-embedding uses persisted jobs and real embeddings; browser evidence exercises OpenClaw's authenticated plugin UI without weakening its sandbox, CSP, CORS, or authentication.

**Technology:** Node.js 24.15.0, npm lockfile, `node:test`, Docker Compose, OpenClaw 2026.8.1-beta.3, LanceDB, SQLite, Transformers.js, OpenAI-compatible lab credentials, PinchTab browser automation.

## Invariants

- OpenClaw is pinned to `2026.8.1-beta.3`; no newer commit enters the build.
- The live OpenClaw service, production files, production Docker resources, and production credentials are read-only and are never restarted or copied.
- All new files and resources remain below `/root/plur1bus-beta-lab` and use a unique `plur1bus-beta-fix-final-750` prefix.
- No OpenClaw bundle or installed `node_modules/openclaw` file is patched.
- No `PLUR1BUS_SKIP_HOST_PATCH`, diagnostic mode, test skip, retry masking, timeout relaxation, or permissive assertion is allowed.
- No push, tag, publish, release, or pull request is created.
- Secrets are consumed only from the existing lab `.env`, never printed or embedded in evidence.
- Any source change after candidate freeze invalidates every final stability run.
