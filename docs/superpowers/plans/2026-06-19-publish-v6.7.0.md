# v6.7.0 Release Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a GitHub Release for `@cyb3rb1ade/plur1bus-memory@6.7.0` with annotated tag, then publish the same `.tgz` to ClawHub.

**Architecture:** Single `.tgz` artifact built once via `npm pack`, validated by clawhub dry-run, then used for GitHub Release (tag + notes) and ClawHub publish in that order. No npmjs.com publish in this flow — `~/.npmrc` routes `@cyb3rb1ade` scope to `clawhub.ai/api/npm/`; the explicit ClawHub CLI publish is the canonical publication step.

**Tech Stack:** git, GitHub CLI (`gh`), ClawHub CLI (`clawhub`), npm (for pack/dry-run only)

## Global Constraints

- Working directory: `/root/openclaw-memory-system`
- Code-freeze base: `a5cc31d` — no code changes after this commit, only docs
- Package: `@cyb3rb1ade/plur1bus-memory@6.7.0`
- Tag: `v6.7.0` as annotated tag, must not already exist locally or on origin
- Artifact staging dir: `/tmp/plur1bus-release/`
- Phase order: Preflight → Tests/Dry-Runs → Build Artifact → ClawHub Dry-Run → **[STOP: summarize before remote steps]** → Push Tag → GitHub Release → ClawHub Publish → Verify
- GitHub Release MUST exist before ClawHub Publish
- No npmjs.com publish unless `npm whoami --registry=https://registry.npmjs.org/` confirms auth and target is explicitly confirmed
- Never bypass ClawHub CLI internal checks — collect output and abort on any error
- Each phase stops on any failure
