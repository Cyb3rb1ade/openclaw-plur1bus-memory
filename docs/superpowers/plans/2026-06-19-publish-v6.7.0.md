# v6.7.0 Release Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish `@cyb3rb1ade/plur1bus-memory@6.7.0` to npm, create a GitHub Release with annotated tag, and register the identical `.tgz` on ClawHub.

**Architecture:** Single `.tgz` artifact built once via `npm pack`, validated by dry-runs against itself, then used for npm publish, GitHub Release attachment, and ClawHub submission — ensuring all three registries receive byte-identical content.

**Tech Stack:** npm, git, GitHub CLI (`gh`), ClawHub CLI (`clawhub`)

- Working directory: `/root/openclaw-memory-system`

- Tag: `v6.7.0` as annotated tag, must not already exist
