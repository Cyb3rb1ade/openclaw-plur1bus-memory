# PLUR1BUS 7.1.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish PLUR1BUS 7.1.0 from the audited main branch as a GitHub Release asset, a GitHub Packages npm package, and a ClawHub package, with verified fresh installations from every channel.

**Architecture:** A short release branch changes only synchronized version metadata and current release documentation. One canonical npm tarball is built and installer-tested before a PR gate; the merged commit is tagged immutably, then each remote publication is verified independently and the release checklist is finalized without moving the tag.

**Tech Stack:** Node.js 22.5+, npm, OpenClaw CLI, git, GitHub CLI, GitHub Packages npm registry, ClawHub CLI

## Global Constraints

- Release title is exactly `PLUR1BUS 7.1.0 - Not just an agent. Yours.`
- Package version is exactly `7.1.0`.
- npm identity remains `@cyb3rb1ade/plur1bus-memory`.
- OpenClaw plugin ID and display name remain unchanged.
- The nested emotional-state-injector remains version `1.0.0`.
- Minimum Node.js remains `>=22.5.0`.
- No new runtime feature, refactor, schema migration, or reranker scoring fix.
- Historical audit-evidence README files remain unchanged.
- Published tags and package versions are immutable.
- All installer smokes use explicit disposable temporary OpenClaw homes.
