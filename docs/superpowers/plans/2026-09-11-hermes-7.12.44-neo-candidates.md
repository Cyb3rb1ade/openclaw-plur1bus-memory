> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the missing non-authoritative candidate lifecycle and bounded candidate recall without duplicating canonical memory ownership.

**Architecture:** A separate scoped LanceDB `neo_candidates` table in the exact active writer namespace stores candidate metadata and optional vectors. Canonical memories retain their existing table/lifecycle. Derive candidate identity from durable native journal turn IDs, not conversation text or fabricated host handles.

**Tech Stack:** Python, LanceDB/PyArrow, existing scoped writer lock and background jobs, temporary fixtures.

## Architectural ruling and limits

Upstream `memoryCandidatesFromTurns` emits candidates independently of bounded
canonical capture; meta-cognition/LightDream can also emit noncanonical behavior
candidates. Therefore native canonical ANN is NOT equivalent to candidate recall.
Use native LanceDB rather than porting the JS Float32 sidecar as another live
vector store. Legacy sidecars remain an explicit import boundary.

Storage Task1 supplies captureId persisted at admission and canonical journal
turn IDs. These are sufficient for candidate retry idempotence; they do not prove
host message deduplication across two independently admitted captures. Do not
require an unavailable Hermes host event handle and then skip all native work.

## Completion boundary

Candidate turn capture and additive recall are distinct from behavioral auto-application.
Derived LightDream/reflection producers may write only noninstructional evidence
with their existing opt-in/visibility gates; automatic behavior changes still
require the separately audited persona/curation policy. Update parity to describe
which producers actually exist and are connected. Native LanceDB storage is the
intentional equivalent to sidecar/index mechanics, not an identical file format.
