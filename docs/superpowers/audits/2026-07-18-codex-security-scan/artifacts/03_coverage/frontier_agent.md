10. **Additional shipped/alternate surfaces** include the packaged emotional-state injector (`package.json:32`, `.openclaw/extensions/emotional-state-injector/index.js:70`) and an alternate older `plur1bus/` runtime tree whose deployment reachability must be resolved separately from the package main.
