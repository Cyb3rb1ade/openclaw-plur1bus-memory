Set up PLUR1BUS now

The assistant is installed — your Hermes profiles are not set up yet.

Open Applications → PLUR1BUS Setup.

  1. Confirm the Hermes home and detect profiles.
  2. Select all existing profiles, the default profile only or individual profiles.
  3. Keep activation enabled, review the plan, authorize setup to stop and reopen Hermes, and install.

Your existing Desktop preferences are preserved. If the navigation entry is absent, enable Desktop in Hermes → Capabilities → Plugins → PLUR1BUS. Open the assistant again to set up profiles created later. No terminal is required.
